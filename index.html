🗄 Supabase データベース設定
データをSupabaseに保存すると、複数端末でリアルタイム同期が可能になります。
supabase.com でプロジェクトを作成し、 Project Settings → API → service_role key を設定してください。
Project Settings > API > Project URL
Project Settings > API > service_role （⚠️GAS側のScript Propertiesに保存されます。フロントエンドに公開されません）
📋 セットアップ手順
  1. SupabaseダッシュボードでNew Projectを作成
  2. SQL Editor で supabase_schema.sql を実行
  3. 上のURL・Service Role Keyを入力して「保存してテスト」
  4. GASを再デプロイ後、「データ移行」タブから既存データを移行
